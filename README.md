# ИИ-Методист с Лалой — версия 0.3 (пилот)

Это **первая версия с настоящим подключением к OpenAI**: чат и углублённый анализ извлечённого текста ДООП. Платформа сохраняет прежние локальные конструкторы КТП, нагрузки, пособий и игр.

## Очень просто — как обновить существующий проект на GitHub и Vercel

Сайт уже опубликован у вас на Vercel. **Не создавайте второй проект**.

1. Распакуйте архив `ii-metodist-lala-ai-vercel.zip`.
2. Откройте свой **существующий** репозиторий GitHub `aimetodist`.
3. На вкладке **Code** нажмите **Add file → Upload files**. Перетащите в окно файлы `index.html`, `package.json` и **целую папку `api`** с файлом `lala.js` внутри. Если GitHub не даёт перетащить папку, создайте в репозитории `api/lala.js` через **Add file → Create new file** и вставьте туда исходный код.
4. Если GitHub спросит о замене `index.html`, подтвердите перезапись новой версией. Нажмите **Commit changes**. Сохраните остальные файлы вашего репозитория; удалять их необязательно.
5. Откройте ваш **уже созданный** проект в Vercel → **Settings → Environment Variables**. Добавьте:
   - **`OPENAI_API_KEY`** — ваш секретный ключ из OpenAI Platform. **Никогда не вставляйте его в GitHub, `index.html` или чат.**
   - **`LALA_ACCESS_CODE`** — придуманный вами сложный код, который будете сообщать только проверенным педагогам (пример не используйте). Код предотвращает свободное использование платного API посторонними, но не заменяет личный кабинет.
   - Необязательно: `LALA_MODEL` = `gpt-5.6-terra` — модель для ответов.
6. Дождитесь автоматического обновления по коммиту GitHub. Если вы добавили переменные **после** публикации, в Vercel **Deployments → Redeploy** текущую версию (чтобы новые переменные вступили в силу).
7. Откройте адрес сайта Vercel, обновите страницу через **Ctrl+F5**, нажмите на маленькую Лалу справа внизу. Введите **код доступа**, спросите «Привет, Лала! Как составить цель программы по художественной направленности?». Должен прийти развернутый ответ.
8. Для проверки программы: откройте «Проверка программ» → загрузите DOCX/PDF/TXT → при желании выполните локальную проверку → впишите код в поле «ИИ-проверка» → поставьте галочку о праве передать текст → нажмите **Углублённая ИИ-проверка**.

## Что будет работать, а что ещё нет

- ✅ Живой ИИ-чат с Лалой через защищённую Vercel Function (`/api/lala`).
- ✅ Углублённый ИИ-анализ распознанного текста документа с замечаниями, связанными с опорной картой рекомендаций 2026 года.
- ✅ Старые локальные функции: проверка по правилам, студии/часы, КТП, конспекты-шаблоны, идеи, карточки, игры.
- ✅ Секретный API-ключ остаётся **на сервере**, не включён в HTML или репозиторий.
- ⚠️ Анализируется извлечённый текст, а не визуальное оформление страниц. Сканированные PDF без текстового слоя и часть таблиц могут не разобратьcя.
- ⚠️ Если текст длиннее 48 000 символов, в ИИ отправляется только начальный фрагмент и интерфейс предупреждает об этом. Поэтому отчёт по длинному документу не является проверкой всей программы.
- ⚠️ Правила основаны на сокращённой **карте критериев** из методических рекомендаций Ставропольского края, а не на полном поиске по каждой странице PDF. AI может ошибаться — проверка методиста обязательна.
- ⚠️ Для публичного сервиса с большим количеством педагогов необходимы персональные аккаунты, настоящие лимиты запросов, мониторинг расходов, политика обработки документов и защита персональных данных. Простой общий код доступа — решение только для тестового запуска.

## Безопасность и оплата

Каждый запрос к OpenAI API может стоить денег. Предусмотрите бюджет, ограничение API-расходов и не делитесь кодом доступа публично. У сервера есть примитивный внутрипроцессный лимит 20 запросов в час на IP, **он не является надёжным распределённым лимитом** для Vercel. Не открывайте сервис для всех желающих до настройки настоящей защиты.

Исходный файл педагога в процессе проверки **не редактируется**. Для ИИ-анализа **извлечённый текст** передаётся с согласия педагога в OpenAI; для локальной проверки документ остаётся в браузере. Не загружайте персональные данные детей и конфиденциальные документы без разрешения и достаточных правовых оснований.

### Если чат не отвечает

- «Лала ещё не настроена» — отсутствует `OPENAI_API_KEY` или `LALA_ACCESS_CODE` в Vercel либо не был сделан Redeploy.
- «Неверный код доступа» — проверьте `LALA_ACCESS_CODE`.
- «Достигнут лимит/средства API» — проверьте баланс и лимиты OpenAI API.
- «404 /api/lala» — папка `api` не попала в корень репозитория или не развернулась в Vercel.
- «Ответ слишком долгий» — уменьшите длину документа или попробуйте повторить позже.

### Состав файлов

- `index.html` — самодостаточная веб-страница, CSS, JavaScript и чиби-изображения внутри.
- `api/lala.js` — защищённый серверный обработчик Vercel.
- `package.json` — сообщает Vercel, что серверный JavaScript использует модули.
- `README.md` — эта инструкция.
