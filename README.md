# ИИ-Методист с Лалой — прототип 0.2

Педагогическая мастерская для дополнительного образования, подготовленная на основе предоставленных пользователем учебных планов МБУ ДО Дворца детского творчества на 2026–2027 год и рекомендаций РМЦ Ставропольского края (2026).

## Установка и GitHub Pages

**Самый простой вариант:** используйте файл `index.html` из архива `ii-metodist-lala-github.zip` — всё (стили, изображения, библиотека чтения Word, программа и таблица часов) уже находится внутри одного HTML-файла.

1. Создайте на GitHub новый репозиторий, например `ii-metodist-lala`. Не заменяйте этим файлом главную страницу другого сайта.
2. На вкладке `Code` нажмите `Add file` → `Upload files`, загрузите `index.html`, затем `Commit changes`.
3. В `Settings` → `Pages` выберите `Deploy from a branch` → `main` → `/(root)` → `Save`.
4. Подождите публикации и перейдите по адресу `https://ВАШ-ЛОГИН.github.io/ii-metodist-lala/`.

Для локального запуска достаточно открыть `index.html` в браузере. Для чтения некоторых PDF нужен доступ в интернет к pdf.js; DOCX читается встроенным JSZip без передачи на сервер. Сканированные PDF без текстового слоя не распознаются.

## Функции версии

- Проверка заголовков, реквизитов и отдельных числовых несоответствий в ДООП по методрекомендациям 2026 года. Это **алгоритмы, не подключённая языковая ИИ-модель**. Полученный отчёт — предварительная проверка, а не утверждение/экспертиза.
- Выбор студии по названию и педагогу; плановые недельные бесплатные и платные часы; калькулятор произвольного распределения количества групп и часов по группам. Категории оплачиваемой и бюджетной нагрузки проверяются раздельно. **Не является учётом фактически проведённых занятий**.
- Конструктор КТП по темам, внесённым педагогом, с календарным распределением и выгрузкой в CSV / Word-совместимый `.doc`. Каникулы и праздничные дни не учитываются автоматически.
- Генератор шаблона конспекта, банк готовых педагогических приёмов, печатные карточки, интерактивная викторина с сохранением HTML.
- Мини-чат Лалы с ответами из справочной базы сайта; свободного ИИ-диалога пока нет.
- На телефонах интерфейс адаптивен. В браузере локально сохраняются черновики КТП.

## Важные правила использования данных

- В бюджетном плане колонка «Итого» — это **количество обучающихся**, а не нагрузка. Часы/неделю рассчитаны как сумма произведений `число групп × часов в неделю на группу`. Контрольная сумма бюджетной части: **477 ч./нед.**, включая **54 ч./нед.** без однозначно атрибутированных педагогов.
- В платном плане использована колонка «Итого часов в неделю»; строки для одного педагога и студии складываются.
- Отдельные строки без педагога не привязаны к конкретному сотруднику; различающиеся инициалы из разных документов не объединены автоматически. Если в учреждении это один и тот же человек, подтвердите и измените запись перед выпуском.
- Название студии «Топотуха»: **9 бесплатных** + **2 платных** = **11 ч./нед.** по предоставленным данным.
- Учебные планы и список педагогов в опубликованном публичном GitHub-репозитории будут видны всем посетителям и доступны в исходном HTML. **Перед публикацией согласуйте раскрытие фамилий, расписания нагрузки и другой служебной информации с учреждением.** При необходимости замените базу на обезличенную.
- Документы, загруженные в проверку, не отправляются на сервер и не сохраняются в браузере. Публичный хостинг статического сайта не обеспечивает личные кабинеты и защищённый обмен документами. Для многопользовательской работы и ИИ нужен отдельный защищённый сервер.
